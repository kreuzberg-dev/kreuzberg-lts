# Kreuzberg LTS

Use the bundled Kreuzberg skill and eight references for existing 4.x applications.
The separately installed CLI must be Kreuzberg 4.x with MCP support; configure KREUZBERG_LTS_BIN if PATH selects another version.
Inspect MCP tools/list for schemas before extraction. Decode JSON from MCP text content; the 4.x extraction result is flat and batches return arrays.
Optional OCR, embeddings and structured extraction require their actual runtime dependencies and credentials.
